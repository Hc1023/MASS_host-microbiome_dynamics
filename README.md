# Host–microbiome dynamics in the MASS cohort

Analysis code and figure source data for a longitudinal study of circulating microbial signals, host transcriptional responses, and mortality in critically ill patients with pulmonary infection. Analyses use the MASS cohort for discovery, CMAISE for external evaluation of host-response patterns and prediction models, and EARLI for comparison of virus-associated transcriptional programs.

The repository covers microbial profiling, host pathway and module analyses, HCMV-associated responses, consensus transcriptomic subtype (CTS) dynamics, and mortality prediction. Figure identifiers correspond to the accompanying manuscript.

## Repository contents

| Location | Contents |
|---|---|
| `code/` | R scripts for analysis, plotting, and validation |
| `Inputs/` | Prepared expression and microbial data, clinical metadata, gene sets, fixed cross-validation assignments, and frozen prediction-model inputs |
| `Outputs/` | Statistical results, fitted objects, and source-data workbooks |
| `Outputs/CMAISE_joint_models/` | Joint-model inputs, fitted objects, estimates, predictions, and diagnostics |
| `Outputs/plot_components/` | Individual plots generated by the analysis and plotting scripts |
| `Figures/` | Individual manuscript figure panels |
| `manifest.csv` | Index linking 63 manuscript panels to their figure files and analysis scripts |

`Outputs/Source_Data.xlsx` contains figure source data. `Outputs/Supplementary_Data.xlsx` provides additional estimates, sample information, and analysis diagnostics. Use `manifest.csv` to locate the code and files for a particular panel; some panels comprise multiple files or PDF pages.

## Analysis overview

| Manuscript figures | Analyses |
|---|---|
| Figures 1–2; Figures S1–S4 | Cohort and sampling summaries, microbial background filtering, microbial–clinical associations, and host expression differences |
| Figure 3; Figure S5 | Longitudinal host pathways, four focused host-response modules, and associations with HCMV |
| Figure 4; Figures S6–S9 | Cell-composition adjustment, subgroup analyses, joint longitudinal–survival models, and external host-response comparisons |
| Figure 5; Figure S10 | CTS assignments and transitions, outcome associations, and accompanying microbial trajectories |
| Figure 6; Figure S11 | Repeated cross-validation, gene-signature models, and external application of frozen MASS models |

The primary MASS endpoint is 28-day all-cause mortality. The CMAISE endpoint is recorded in-hospital death within 28 days. In CMAISE joint models, live discharge is censored at discharge and follow-up is capped at day 28. The Methods and figure legends specify the sample set, covariates, tests, and multiple-testing family for each analysis.

## Software environment

The recorded analysis environment uses R 4.5.0. Principal dependencies include:

- Expression and enrichment: `edgeR`, `limma`, `GSVA`, `fgsea`, `clusterProfiler`, `AnnotationDbi`, and `org.Hs.eg.db`.
- Longitudinal and survival modeling: `lme4`, `lmerTest`, `nlme`, `emmeans`, `survival`, and `JM`.
- Classification and prediction: `ConsensusTranscriptomicSubtype`, `sva`, `randomForest`, `glmnet`, and `pROC`.
- Other analyses and visualization: `xCell`, `MaAsLin3`, `vegan`, `tidyverse`, `ComplexHeatmap`, and `circlize`.

Consult `Outputs/sessionInfo.txt` and `Outputs/CMAISE_joint_models/sessionInfo.txt` for recorded package versions. Individual scripts declare their additional dependencies.

## Running the analyses

Run commands from the repository root so that relative paths resolve correctly. The scripts start from prepared data; this repository does not provide an end-to-end workflow from raw sequencing reads.

List the stages supported by the analysis runner:

```sh
Rscript code/run_current_analysis.R --list
```

Run selected stages in the specified order, for example:

```sh
Rscript code/run_current_analysis.R \
  Figure4C_FigureS9CD_joint_models.R \
  validate_CMAISE_models.R \
  Figure4C_FigureS9CD_joint_plot.R
```

Other analyses can be run directly using the scripts listed in `manifest.csv`, for example:

```sh
Rscript code/Figure6D_analysis.R
Rscript code/Figure6D_plot.R
```

Analysis and plotting commands write numerical results and individual plots to their designated output paths and can replace existing results.

`Rscript code/run_current_analysis.R --all` runs all stages listed by the runner, including model fitting. The runner covers the linked host-response, CTS, and model workflows; scripts for other manuscript analyses remain separate.

## Reproducibility and input requirements

Analysis-specific prepared inputs and saved results are retained to make the reported numerical results traceable. Input filenames containing dates identify source snapshots. Preserve sample identifiers and the supplied participant-level fold assignments when reproducing the analyses.

Some stages still require source materials outside this directory: the module-augmented prediction workflow reads saved out-of-fold predictions from the original analysis directory. The module-comparison validation script also uses an external audit-output location. These paths are explicit in `Figure6B_FigureS11A_analysis.R` and `validate_module_scores.R`. Configure those source and output paths before running the corresponding stages; the complete reconstruction workflow is not currently a self-contained installation.

CTS analyses use the original stored assignments in `Inputs/1616_meta_model.rdata` (MASS) and `Inputs/260830_SRR_CTS_classification.csv` (CMAISE), without reclassification. The original MASS snapshot contains 17 early-sample label–probability discrepancies; these are retained and documented in `Outputs/CTS_original_label_probability_audit.csv`. Probability models use the original stored probabilities separately from categorical analyses. MASS module analyses use a common score matrix and subset it for each analysis rather than repeating normalization within subgroups.

Candidate genes, modules, and expression preprocessing were prepared before prediction resampling. Cross-validation therefore evaluates model fitting conditional on those choices. External prediction applies frozen MASS coefficients without refitting or recalibration. Joint models that include eventual outcome in the longitudinal component describe retrospective outcome-associated trajectories. These distinctions are maintained in the accompanying Methods and Results.
